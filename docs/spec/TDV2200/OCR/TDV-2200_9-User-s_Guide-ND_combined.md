## 1. INTRODUCTION

This terminal is used for communication with a host computer. The host computer may be located anywhere; in the same room as the terminal, somewhere else in the building or even in another country. The behaviour of the terminal in any work situation is determined by the program residing in the host computer.

This guide describes the features of the terminal and how these features can be put to best use.  
For a detailed description of how to operate your terminal in your work situation, consult your local operating instructions.  

**NOTE:** Programming specifications in addition to those included in this guide are contained in the "TDV 2215 Functional Specifications".  
It has publication number 5176 and part number 385604 and can be ordered from Tandberg Data A/S.  

## 2. CONTROLS AND ADJUSTMENTS

### 2.1 Turning the Terminal On

Turn the terminal on with the power on/off switch located on the left-hand side. A blinking cursor appears in the top left hand corner (home) of the screen.

### 2.2 Time-out

If the terminal is set up with time-out, the screen will go blank after ten minutes if there has been no action on the terminal. This is done to conserve the phosphor of the screen. To get back to normal operation, press CTRL CLEAR (Refer to page 26).

### 2.3 Adjusting Light Intensity

The light intensity control is located above the contrast control. Adjust the intensity according to the light conditions in the room.

### 2.4 Adjusting Contrast

Use the contrast control to adjust the contrast between characters and background. Recommended contrast is obtained by turning the control to mid-position. The control is located above the power on/off switch.

# 2.5 Adjusting Height, Tilt and Swivel

**Height:** Pull knob A on the right hand side of the stand and turn to adjust to desired height. Make certain that the knob is properly locked when the adjustment is complete.

**Tilt:** The force required to tilt the terminal can be adjusted with knob B. Turn knob B until the terminal can be tilted easily while remaining stable at any angle. Once a comfortable angle has been found, the tilt can be secured by tightening the knob.

**Swivel:** The force required to swivel the terminal can be adjusted with knob C. Turn knob C until the terminal can be swivelled easily. Once a comfortable angle has been found, it can be secured by tightening the knob.

## 3.2 Working Posture

The keyboard is connected to the display unit by a flexible twisted cable which allows freedom in finding the best position for both units. The desk plate on which the keyboard is placed, should be high enough to allow room for the knees, and low enough for the forearms to be as horizontal as possible when the hands rest on the keyboard.

Statistical surveys indicate that heights in the range 65 to 68 cm from floor to underside of desk plate fit most operators. Desks with adjustable legs are available. A foot rest and an adjustable chair will often help to provide the best possible working posture.

# 4.3 Keyboard Lamps

Two groups of lamps are located on the upper part of the keyboard.

The left four (EXP, APP, BUSY and MSG) are for application use. Consult your local operating instructions for further information.

The right group consists of five lamps:

- **LINE** — Lights when the terminal is online to the host computer.
- **WAIT** — The terminal tries to go online, but the modem does not respond properly.
- **CAR** — Reflects the Carrier Detect signal from the modem.
- **ERROR** — Indicates an error in communication with host computer (overrun, parity, format....)
- **ON** — Power On indicator

# 4.4 The Repeat Function

All the keys have repeat in the Unshift mode. CTRL as lead-in disables the repeat for all keys. Shift as lead-in disables the repeat only for those function keys generating different codes in shift and unshift.

# 4.5 Shift Lock

Shift lock gives shift in the grey area of the keyboard. Shift lock is ignored for arrows, delete, escape, LF (line feed) and CR (carriage return). All other function keys are disabled when shift lock is active.

# 5. RESET SWITCH

The RESET switch is located underneath the CRT-housing on the left hand side.

RESET is a kind of "EMERGENCY EXIT" used if the terminal for some reason "goes crazy," or if the keyboard hangs and there is no way to "repair" the situation from the keyboard. RESET should be used instead of power off-on in such cases. RESET affects the soft-switches as power off-on; clears the screen and sets the terminal in online state.

If the RESET switch is pressed while inside full screen programs (such as NOTIS-WP), the function keys may not give normal results. The output may then contain "rubbish" instead of cursor control codes, erase screen and so on. In order for the function keys to give normal results, you should exit from the program and then start up again.

# 6. CONFIGURATION MENU

The terminal can be set up in several ways to operate in different installations. The setting can be easily accomplished with the soft-switches in the Configuration Menu. Changing the switch-settings can be done from the keyboard or from a program in the host computer.

The soft-switch menus are grouped at three levels. You enter at level ENTRY and exit at level EXIT. At level UPDATE there are five sub-menu pages each containing several soft-switches. 

The user always enters level ENTRY by pressing CTRL HELP twice. From here, the user may enter one of the five sub-menus in level UPDATE by pressing the ENTER key. When the updating (altering) of the switch settings, PUSH-keys etc. is finished, the user leaves level UPDATE via level ENTRY to level EXIT by typing ESC.

## Enter the Configuration Menu

Enter the Configuration Menu at level ENTRY by pressing CTRL HELP twice.

The menu gives you the choice between five sub-menus listed on the screen:

- **Convenience switches** - to alter operator choices of personal preferences.
- **Function Switches** - to make the terminal match the requirements of the program(s) in the host computer.
- **Communication Switches** - for setting up the electrical communication characteristics of the terminal.
- **PUSH-keys** - for programming the 16 PUSH-keys.
- **Tabulation Rack** - for setting up the horizontal tabulator.

In the following we shall describe in more detail the Convenience Switches and PUSH-keys. The Function Switches, Communication Switches and Tabulation Rack are listed but not discussed in depth.

To choose among the five sub-menus, you move the cursor to the one you want to enter by using the up- and down-arrows, and then press ENTER.

## 6.2 How to Alter the Convenience Switches

If you enter the Convenience switch menu, you can set up your choice for the following:

| Switch Name    | Switch Settings     | Comments |
|----------------|---------------------|----------|
| Cursor Type    | Line or Block       | If a "Block" cursor is placed on a character, this character will appear in inverse video. |
| Key Click      | On or Off           | A soft click sounds each time a key is pressed if Key Click is ON. |
| Margin Bell    | On or Off           | If On, the beeper will sound when the horizontal screen column 72 is reached. (Unshift). |
| Auto Repeat    | On or Off           | If On, all keys will have repeat when kept depressed. |
| Key Rollover   | Enabled or Disabled | **Enabled:** If two or more keys are pressed simultaneously, ALL keys will be sent to the terminal. **Disabled:** If two or more keys are pressed simultaneously, only the key detected as the FIRST key will be sent to the terminal. (The others will be ignored) |

# 6.3 How to Program the PUSH-keys

The PUSH-keys (Programmable Utility for String Handling) enable the user to generate a sequence of characters by pressing one single key. The eight PUSH-keys work in both Shift and Unshift, thus allowing 16 different often used strings or code sequences to be programmed and easily retrained.

PUSH-key programming is either allowed or prohibited according to what has been selected in the Function Switch Menu. If you decide to choose the PUSH-key sub-menu while in the Configuration Menu, one of the following two things will happen:

1. The PUSH-key menu will appear on the screen.
2. The word "Prohibited" will appear blinking on the screen.

Each key has a restricted number of characters reserved for it, which means you can use up to the following number of keystrokes per PUSH-key:

| PUSH-key  | Keystrokes |
|-----------|------------|
| P1 = P8   | 12         |
| P9 = P12  | 32         |
| P13 = P16 | 48         |

Non-alphanumeric keystrokes are displayed in the PUSH-key menu as a block. If the left-, right-, up-, down- or home-arrows or SI, SO or ESC are to be assigned to a PUSH-key, they must be "led-in" one by one with an SI-character. Press the CTRL-key and the F52-key (SI) simultaneously as lead-in before one of the arrows or SI, SO, ESC.

To move around in the menu area you use the left-, right-, up-, down- and home-arrows.

To erase characters assigned to a PUSH-key, overwrite them with a SPACE.

Some of the PUSH-keys may already have been used in the application program and sequences assigned to them. Consult the person responsible before altering these PUSH-keys.

To leave the PUSH-key menu press ESC. You will then be back in the Configuration Menu.

# Example: Use of PUSH-keys

Each time you enter NOTIS you will need to type

    NOTIS-WP CR (Carriage Return)

Saved under a PUSH-key, you instead can press one single key to enter NOTIS.

P1's input-line in the PUSH-key menu page will then look like this:

    P1 : NOTIS-WP

(The block will appear when the CR-key is hit.)

# 6.4 Tabulation Rack

Since most application systems have their own tabulator setting systems (NOTIS-WP, PED, ......), the local tabulations will be overridden by the application system.

# 6.7 Leaving the Configuration Menu

To leave the Configuration menu at Level ENTRY you press ESC. This brings you to the **Configuration Exit** at Level EXIT.

In this exit menu you have the following choices:

- **Make Switches Permanent**:  
  ENTER at this field makes the current choices of all fields in sub-menus except Tabulation Rack permanent, i.e. they are written to the non-volatile memory and become the state at power on / reset.

- **Reset to Initial Switches**:  
  ENTER at this field reads the contents of the non-volatile memory back and sets all switches in all sub-menus except Tabulation Rack according to it.

- **Make Tabulation Rack Permanent**:  
  ENTER at this field makes current tabulations permanent, i.e. they are written to the non-volatile memory and become the state at power on / reset.

- **Reset to Initial Tabulation Rack**:  
  ENTER at this field reads the contents of the non-volatile memory back and sets tabulations according to it.

**NOTE**:  

PUSH-keys are ALWAYS permanent independent of switch settings in the Configuration Exit Menu.

| CSI y;x<H>        | Position cursor to co-ordinates y;x       |
| CSI <n>A          | Cursor up n lines                         |
| CSI <n>B          | Cursor down                               |
| CSI <n>C          | Cursor right                              |
| CSI <n>D          | Cursor left                               |
| CSI 80 h          | Numeric pad to "Function" mode            |
| CSI 80 l          | Numeric pad to "Numeric" mode             |

**NOTES:**

1. A set of lamps may be set by specifying a set of lamp numbers separated by ','. If no numbers are specified, all lamps are cleared by the clear function and no lamps are affected by the set lamp and reset lamp functions.

2. See function switches for setting national variants. This sequence does not affect the keyboard.

3. y;x may be omitted, giving cursor home.

4. n may be omitted, giving default 1 line/column.
