# TDV 1200 Control Codes Reference for Terminal Emulation

This document outlines the control codes used by the TDV 1200 terminal, based on ISO standards, ANSI, VT100 compatibility, and ND/TDV-specific extensions. Codes are categorized by standard compatibility for easier emulation implementation.

---

## C0 Control Codes

| Hex | Mnemonic | Interpretation            | Standard          |
|-----|----------|---------------------------|-------------------|
| 00  | NUL      | Null                      | ANSI/ISO 6429     |
| 07  | BEL      | Bell                      | ANSI/ISO 6429     |
| 08  | BS       | Backspace                 | ANSI/ISO 6429     |
| 09  | HT       | Horizontal tab            | ANSI/ISO 6429     |
| 0A  | LF       | Line feed                 | ANSI/ISO 6429     |
| 0B  | VT       | Line feed (Vertical Tab)  | ANSI/ISO 6429     |
| 0C  | FF       | Clear screen              | ANSI/ISO 6429     |
| 0D  | CR       | Cursor return             | ANSI/ISO 6429     |
| 0E  | SO       | Shift out                 | ANSI/ISO 6429     |
| 0F  | SI       | Shift in                  | ANSI/ISO 6429     |
| 11  | DC1/XON  | Transmission on           | ANSI/ISO 6429     |
| 13  | DC3/XOFF | Transmission off          | ANSI/ISO 6429     |
| 1B  | ESC      | Escape                    | ANSI/ISO 6429     |

## CSI Queries and Responses

The host can query the terminal using CSI sequences. The terminal responds with standardized or TDV-specific sequences.

| Query (from host)    | Response (from terminal)             | Meaning                                     | Standard     |
|----------------------|---------------------------------------|---------------------------------------------|--------------|
| CSI 0 c              | ESC [ ? 1 ; 2 c                      | Identify terminal type                      | VT100/ANSI   |
| CSI > 0 c            | ESC > 0 ; 115 ; 0 c                  | Identify firmware (115 = TDV-specific code) | TDV Specific |
| CSI 6 n              | ESC [ Pl ; Pc R                      | Report cursor position                      | VT100/ANSI   |
| CSI 5 n              | ESC [ 0 n                            | Status OK                                   | VT100/ANSI   |

Where:
- `Pl` = current row (line) number
- `Pc` = current column number

These sequences help the host determine terminal capabilities and current state.
