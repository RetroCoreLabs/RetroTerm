It is the most-referenced status document in the repo and it under-reports the shipped feature set.
**Verified** against the source tree:

| Claim in FEATURE-STATUS.md | Reality | Evidence |
|---|---|---|
| Settings Window — *Not Started* | Exists | `src\RetroTerm.Desktop\Views\PreferencesWindow.axaml` |
| Tab Management — *Not Started* | Exists | `TabStrip`, `MainWindow.axaml:261`; `TerminalPopoutWindow.axaml` |

| Protocols: Telnet + SSH only | Also Kermit + ND-100 WebSocket gateway | `src\RetroTerm.Core.Protocols.Kermit\`, `docs\ND100-GATEWAY.md` |

(`src\RetroTerm.Core\Logging\`, `ProtocolMonitorWindow.axaml`), session data logging
(`FileSessionDataLogger.cs`), the terminal bell, the OPCOM / gateway debug windows, and ISO 646
national variants in display and keyboard.

**Action:** rewrite it from the source tree before relying on it again.

### 3.3 One retired doc was actively misleading

`docs\TDV2200-KEYBOARD-MAPPING.md` documented the Alt-combination key strategy that was **deleted**
and replaced by `TDVKeyBindingConfiguration` (arbitrary key combo → grid position). Anyone reading it
would have implemented against a design that no longer exists. Now in `garbage\docs\`.

`docs\TDV-KEY-IMPLEMENTATION-STATUS.md` led with "Query/Response Not Wired ⚠️ CRITICAL" — that has
worked since November 2025. Also retired.

## 4. Genuinely open work

### 4.1 Verified absent from `src\`

1. **TDV 2200 printer / auxiliary-port support.** Design is complete and detailed in
   `docs\TDV-PRINTER-SUPPORT-DESIGN.md`; there is **no printer code at all** — no `*Printer*.cs`
   anywhere under `src\`. This is the largest ready-to-start item.

### 4.2 Blocked

2. **TDV keyboard hardware validation** (`docs\TDV-KEYBOARD-HARDWARE-VALIDATION.md`) — no physical
   ND-246 / TDV-2200/9 available for wire capture. Editing keys (E13, E14, G47 STRYK, B47 ←, PC
   Backspace/Delete) and Ctrl-modifier behaviour have spec conflicts that cannot be settled without
   hardware.

### 4.3 Reported but not re-verified in this pass (*unverified*)

3. VT emulator family — VT52 / VT220 / xterm / ANSI Not Started; VT100 partial (missing DEC private modes)
4. Serial protocol — Not Started
5. Glyph cache and dirty-region tracking — Not Started (rendering performance)
6. Scroll-region defect (cursor positioning outside the region), ~10–15 comprehensive test failures
   (character-set designation, rectangle ops, double height/width), line-drawing cursor position
7. 41 skipped tests — scroll region 4, Avalonia context ~6, TCP timing ~8, other ~23

**The test suite was not run during this cleanup.** Item 7's numbers come from the document, not from
a run.

### 4.4 Deliberately deferred to v2.0

IBM 3270 / TN3270, graphics (ReGIS / Sixel / Tektronix), Blazor Web UI.

### 4.5 Unresolved spec questions (`OPEN-QUESTIONS.md`, all still TBD)

- **Q1.1** TDV2200/9 functional spec — no equivalent to TDV1200's ND-12054-1-EN; reverse-engineered from ROM dumps
- **Q1.2** TDV graphics-extension board protocol — no documentation found
- **Q2.1** SINTRAN packet format — only `0x21 0x13 [protocol]` known; server/PAD ID placement, sequence numbers, flow control unknown
- **Q2.2** X.25 gateway multiplexing — assumed absent, to be made configurable
- **Q2.3** SINTRAN file-transfer protocol — protocol ID, frame format, commands unknown
- **Q2.4** TAD transparent protocol (`0xDD`) — usage and data format unclear
- **Q2.5** SINTRAN routing protocol (`0xDE`) — routing-table format and commands unclear
