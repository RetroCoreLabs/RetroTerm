### Physical Keyboard Label Interpretation

The physical keyboard shows **BOTH** labels:
- **Top label**: F1-F8 (Function key labels for user reference)
- **Bottom label**: The actual character/function they send

So the keys are labeled:
- **E51**: "F5" label, sends "000" (three zeros)
- **E52**: "F6" label, sends "00" (two zeros)
- **E53**: "F7" label, sends "0" (single zero)
- **E54**: "F8" label, sends "+" (plus sign)
- **F51**: "F1" label, sends RS (0x1E)
- **F52**: "F2" label, sends US/SI (0x1F)
- **F53**: "F3" label, sends CAN/ESC (0x18)
- **F54**: "F4" label, CLEAR function
