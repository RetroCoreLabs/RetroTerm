## CSI Queries and Responses

The host can query the TDV 2220 terminal using CSI sequences. The terminal responds with standardized or TDV-specific sequences.

| Query (from host)    | Response (from terminal)             | Meaning                                     | Standard     |
|----------------------|---------------------------------------|---------------------------------------------|--------------|
| CSI 0 c              | ESC [ ? 1 ; 2 c                      | Identify terminal type                      | VT100/ANSI   |
| CSI > 0 c            | ESC > 0 ; 115 ; 0 c                  | Identify firmware (115 = TDV-specific code) | TDV Specific |
| CSI 6 n              | ESC [ Pl ; Pc R                      | Report cursor position                      | VT100/ANSI   |
| CSI 5 n              | ESC [ 0 n                            | Status OK                                   | VT100/ANSI   |

Where:
- `Pl` = current row (line) number
- `Pc` = current column number

These sequences help the host determine terminal capabilities and current state.

## Notes
- **VT100 Compatible** codes are generally found in DEC VT100 terminal documentation and widely supported.
- **TDV Specific** codes are extensions or unique to the TDV 2220, particularly the `EF`, `EA`, `NP`, `PP`, `CTC`, `SM`, `MC`, `RM`, and `DAQ` sequences.
- CSI sequences often take numeric arguments (n), and some (marked `ms`) may take multiple parameters separated by semicolons.

Use this as a reference when implementing the emulator's control sequence parser and terminal state machine.
