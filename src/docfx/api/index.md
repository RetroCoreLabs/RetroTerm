# API Reference

Generated from the XML documentation of the RetroTerm projects. The tree on the left lists every
namespace, type and member. The namespace of a type starts with the name of its project:
`RetroTerm.Core` holds the terminal emulators, the escape-sequence parser, the screen buffer,
graphics and the session; `RetroTerm.Core.Protocols` and its siblings hold the connections and
Kermit; `RetroTerm.Mcp` the MCP server; `RetroTerm.Desktop` the Avalonia application.
